# 🌾 Precision Agriculture Analytics with AI-Driven Insights

## 📌 Project Overview

This project is a cloud-based AI-powered precision agriculture platform developed using Python, Streamlit, TensorFlow, Scikit-learn, and Microsoft Azure.

The system simulates agricultural IoT sensor data, performs AI-driven irrigation prediction, detects crop diseases using deep learning, and uploads agricultural data to Azure Blob Storage for cloud integration.

---

# 🚀 Features

- Real-time IoT sensor simulation
- Live analytics dashboard
- AI irrigation prediction
- Crop disease detection using CNN
- Azure Blob Storage integration
- Real-time alerts and recommendations
- Interactive visualization using Plotly

# ☁️ Cloud Integration

---

# 🤖 AI Features

## Irrigation Prediction

Machine Learning model predicts whether irrigation is required based on:
- Soil moisture
- Temperature
- Humidity
- Soil pH
- Light intensity

---

## Crop Disease Detection

CNN-based deep learning model detects:
- Healthy crops
- Early Blight disease
